# Reference

## Set up your organization - onboarding

- `app/app-customer/src/page/onboarding/customer-onboarding.ts`: The onboarding stepper and its steps.
- `app/app-customer/src/page/onboarding/customer-onboarding-profile.ts`: Name, language and currency fields.
- `app/app-customer/src/page/onboarding/customer-onboarding-location.ts`: Permanent storage-location selection.
- `app/app-customer/src/machine/stepper.ts`: Step completion rules and transitions.
- `app/app-customer/src/page/onboarding/customer-onboarding-plans.ts`: Trial and plan selection.
