# App User Settings

The **App User Settings** page configures the default visual and language preferences applied to respondents and visitors when they land on resources managed by this team (such as surveys or forms).

## Overview

When respondents open a public or invited survey, the team's app user settings establish the initial presentation before personal respondent preferences or URL presets are applied:

- **Language (`language`)**: The default language code (e.g., `en`, `fr`, `es`) applied to respondents when they land on team-managed spaces. If a survey supports multiple languages, this setting determines the initial language fallback.
- **Theme (`theme`)**: The default visual theme applied to respondents viewing team surveys.

## Interface Elements

- **Language Field**: Text field specifying the default language identifier.
- **Theme Field**: Text field specifying the customer theme token to apply to respondent views.
