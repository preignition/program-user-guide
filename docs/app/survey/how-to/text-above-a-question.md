# Putting text above a question

::: info
This page is about forms using the **one question per page** layout. In the **multiple questions per page** layout, text blocks already appear wherever you place them, so nothing on this page is needed.
:::

## Text above a question

In **one question per page** mode, each question gets its own page. When you place a text block immediately before a question **in the same section**, the text is shown at the top of that question's page — an ideal way to introduce or explain a question.

1. In the form editor, add a **text** block to a section.
2. Type the introduction in the text block.
3. Add the question directly below the text block, in the same section.

The text and the question now share one page: the text appears first, followed by the question and its answer options.

## Keeping a text block on its own page

By default, text placed before a question groups with it. If you want a text block to remain on its own page:

1. Open the text block's settings.
2. In **advanced mode**, switch on **End Page**.

A text block with **End Page** switched on ends the current page — it does not attach to the question that follows. Texts placed *after* the question always keep their own page.

### Examples

| Content in a section | Pages respondents see |
| :--- | :--- |
| Text, Question | One page: text above the question |
| Text (End Page), Question | Two pages: the text alone, then the question |
| Question, Text | Two pages: the question, then the text |

## Where grouping applies

- Grouping only happens within a **section** — a text block never joins a question in another section.
- The question determines the page's title in the menu and its visibility logic. A text block with its own visibility logic still hides or shows on its own.
- The **End Page** flag has no effect in the **multiple questions per page** layout.
