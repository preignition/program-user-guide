# Discussion App Release Notes

## Version 1.0.0

The Discussion App provides a community forum for collaborative communication between Accessible Surveys customers, teams, and survey respondents. It enables users to create discussions, post comments, reply to threads, upvote contributions, and react to content.

### Objectives

- **Customer Collaboration:** Facilitates communication between Accessible Surveys customers to ask questions, share research ideas, provide product feedback, and foster community support.
- **Survey Feedback Channels:** Provides spaces for survey respondents to ask questions and share feedback regarding specific surveys or question phrasing.

### Core Features

- **Discussion Directory:** The main entry point lists channel discussions with category filters, author details, creation timestamps, comment counters, participant avatars, and vote totals.
- **Three-Tier Conversation Model:** Discussions are structured hierarchically:
  1. **Discussions:** Main topic posts.
  2. **Comments:** Direct responses to a discussion topic.
  3. **Replies:** Nested replies to individual comments.
- **Categories:** Channel owners organize topics using standard categories:
  - `General`: Open community conversations.
  - `Questions`: Question-and-answer threads supporting accepted answer marking.
  - `Ideas`: Feature proposals and research suggestions.
  - `Feedback`: User experience feedback and constructive reviews.
  - `Bug Reports`: Reporting technical issues and regressions.
  - `Announcements`: Official updates (restricted to channel owners and moderators).
- **Accepted Answers:** On question threads, discussion authors can mark a comment as the accepted answer. The selected solution is highlighted at the top of the comment stream for easy discovery.
- **Rich Text & Accessibility:** Discussions and comments are authored with Markdown, allowing formatted headings, lists, links, and code blocks.
- **Reactions & Voting:** Signed-in participants can upvote helpful topics and react to comments.
