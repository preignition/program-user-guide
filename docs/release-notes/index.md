# Release Notes

Stay up to date with the latest improvements and features across the Accessible Data platform.

## Customer Portal & Platform API

* **[Team API Keys & Data Definition Endpoints (1.2.0)](./2026-08-11-api-keys-and-definition-endpoints.md)**: Manage team API keys in Team Settings and query typed data schemas via definition endpoints and OpenAPI reference.

## Survey App

* **[Interactive Survey Analytics & Behavioral Insights (2.4.0)](./2026-11-18-analytics-and-behavior.md)**: Explore survey results with an entirely redesigned, interactive analytics page, and discover how respondents experience your survey with brand-new behavioral insights.
* **[Catch Issues Early, Stay in Touch Effortlessly (2.2.0)](./2026-10-20-survey-emails-and-review.md)**: Review your survey for broken logic, missing translations, accessibility issues, and wording problems before you publish, navigate the structure tree with one-click column filters for media and review findings, audit and manage all logical expressions in one place, invite reusable team audiences with unique links and live progress tracking, and reach respondents with privacy-first confirmations, reminders, and follow-ups.
* **[Improved One-Question-Per-Page Layout (1.3.1)](./2026-08-16-one-question-per-page-layout.md)**: Choose the layout at survey creation, put free text above questions, and enjoy a sticky navigation bar and larger text by default.
* **[Section Library, Cross-Survey Sharing & Smart Pre-Fill (1.3.0)](./2026-08-15-section-library-and-sharing.md)**: Share standardized sections, embed live references or copies, and eliminate respondent fatigue with cross-survey pre-fill.
* **[Marketing Campaigns & UTM Link Building (1.1.0)](./2026-07-08-campaigns-and-utm-tracking.md)**: Track acquisition channels and easily configure UTM queries in advanced mode.
* **[Survey Item Randomization (1.0.2)](./2026-05-28-survey-randomization.md)**: Reduce order bias by shuffling options, questions, and sections.
* **[Account Email Synchronization (1.0.0)](./2026-05-27-account-email-synchronization.md)**: Seamless identity verification in surveys with the Account Email question type.
* **[Confidence Index & Behavioral Tracking (1.0.1)](./2026-05-25-confidence-index.md)**: Detect bots and analyze respondent interaction patterns with behavioral signals.
* **[Scroll Page Before Next (1.0.0)](./2026-05-20-scroll-page-before-next.md)**: Require respondents to scroll to the bottom of long or mandatory pages before advancing.

## Listserv App

* **[Audience Import for Listserv Channels (1.1.0)](./2026-11-03-listserv-audience-import.md)**: Seed a channel from a reusable team Audience in Channel Settings → Audience Import, preview every recipient outcome before committing, record an explicit consent warranty, and audit every run in a privacy-first import history.

## Shared Components

* **[Theme-Aware Markdown Content (1.1.6)](./2026-06-05-theme-aware-markdown.md)**: Create content and logos that automatically adapt to light and dark themes using new visibility classes and simplified block directives.
